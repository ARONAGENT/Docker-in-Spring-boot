Through this project, you'll gain hands-on experience with Docker fundamentals, including container management, image creation, networking, storage, and orchestration using Docker Compose for multi-container applications.

## 🐳 Docker Platform Overview

Docker is the platform that enables the creation, management, and execution of containers. Containers handle the isolation, packaging, and consistent environment, but Docker provides the tools and infrastructure that make working with containers easy and efficient.

**Docker as a Platform provides:**

- **Docker Runtime** - Core engine for running containers
- **Image Creation and Management** - Build, store, and distribute container images
- **Networking** - Container communication and network isolation
- **Security** - Container isolation and access control
- **Volume and Storage Management** - Persistent data management

## 📋 Docker Commands Reference

### Essential Docker Commands

| Command | Description |
|---------|-------------|
| `docker run -d -p 8080:80 nginx` | Creates and starts a new container in detached mode, mapping host port 8080 to container port 80 |
| `docker ps -a` | Shows all containers (running + stopped) |
| `docker stop <container_id>` | Stops a running container gracefully |
| `docker start <container_id>` | Starts an existing stopped container (does not create a new one) |
| `docker rm <container_id>` | Deletes a stopped container permanently |
| `docker images` | Lists all Docker images available on the system |
| `docker rmi <image_name>` | Removes a Docker image from the system |
| `docker pull <image-name>:<tag>` | Downloads an image from Docker Hub |
| `docker container prune` | Deletes all stopped (inactive) containers at once |
| `docker logs <container-id>` | Displays logs/output generated by a container |
| `docker inspect <container-id>` | Shows detailed configuration and metadata of a container |
| `docker stats` | Displays real-time CPU, memory, and network usage of running containers |

## 🐙 Docker Compose Configuration

### Service Configuration Options

```yaml
services:
  app:
    image: image-name:tag
    container_name: custom-container-name
    ports: 
      - "8080:80"  # Maps host:container ports
    volumes:
      - ./data:/app/data  # Mount host directory to container
    environment:
      - POSTGRES_DB=mydatabase
    depends_on:
      - database  # Ensures database starts first
    networks:
      - app-network
```

### Docker Compose Commands

| Command | Description |
|---------|-------------|
| `docker-compose up` | Start all services defined in docker-compose.yml |
| `docker-compose down` | Stop and remove all containers, networks |
| `docker-compose build` | Build or rebuild services |
| `docker-compose start` | Start existing containers |
| `docker-compose stop` | Stop running containers without removing |
| `docker-compose ps` | List containers for services |
| `docker-compose logs <service-name>` | View logs for specific service |

## 🚀 Installation

### Prerequisites

Before you begin, ensure you have the following installed:

- Java 17 or higher
- Docker Desktop (Windows/Mac) or Docker Engine (Linux)
- Docker Compose
- Git
- Maven or Gradle

### Setup Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/ARONAGENT/Docker-in-Spring-boot.git
   cd Docker-in-Spring-boot
   ```

2. **Install Docker**
   - Visit [Docker Official Website](https://www.docker.com/) and download Docker Desktop for your OS
   - Follow the installation instructions for your platform
   - Verify installation:
     ```bash
     docker --version
     docker-compose --version
     ```

3. **Build the Spring Boot application**
   ```bash
   ./mvnw clean package
   ```

4. **Build the Docker image**
   ```bash
   docker build -t spring-boot-docker-app .
   ```

5. **Run with Docker Compose**
   ```bash
   docker-compose up -d
   ```

6. **Access the application**
   - Application: http://localhost:8080
   - Database: localhost:5432

## 💻 Usage

### Running Individual Containers

```bash
# Run the Spring Boot application
docker run -d -p 8080:8080 --name spring-app spring-boot-docker-app

# Run PostgreSQL database
docker run -d -p 5432:5432 --name postgres-db \
  -e POSTGRES_DB=mydb \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=password \
  postgres:15
```

### Using Docker Compose

```bash
# Start all services
docker-compose up -d

# View logs
docker-compose logs -f

# Stop all services
docker-compose down

# Rebuild and restart
docker-compose up -d --build
```

### Monitoring Containers

```bash
# View running containers
docker ps

# Check resource usage
docker stats

# View logs
docker logs <container-id>

# Inspect container
docker inspect <container-id>
```
